# Programação Orientada a Objetos com C#

Repositório de estudo para aprender os conceitos de Programação Orientada a Objetos (POO) através de aulas práticas e exercícios em C#.

## Visão Geral

Este repositório documenta uma jornada de aprendizado pelos fundamentos de POO, começando com conceitos básicos até padrões mais avançados. Cada aula se constrói sobre o conhecimento anterior com implementações práticas.

## Conceitos Principais

- **Encapsulamento**: Proteção de dados com modificadores de acesso e propriedades
- **Herança**: Criação de hierarquias de classes
- **Polimorfismo**: Métodos virtuais e sobrescrita (override)
- **Abstração**: Classes abstratas e imposição de contratos
- **Interfaces**: Definição de contratos para implementação
- **Associação**: Relacionamento entre classes
- **Injeção de Dependência**: Arquitetura com baixo acoplamento
